# 🚌 OpenOMSI-Leitstellen-Addon

Willkommen beim offiziellen OpenOMSI-Leitstellen-Addon!

Mit diesem Addon können Spieler einen realistischen Leitstellenbetrieb in OpenOMSI organisieren.

## Funktionen
- Live-Leitstelle mit Kartenübersicht
- Integrierter Busfunk
- Sprechwünsche und Leitstellenrufe
- Dienst- und Umlaufzuteilung durch Disponenten
- Mehrere Disponenten pro Leitstelle
- Gemeinsame Multiplayer-Fahrten
